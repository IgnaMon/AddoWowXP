# Instalación de LevelPercent

## Paso 1: Copiar el addon

Copia la carpeta `LevelPercent` en la carpeta de addons de World of Warcraft.

### Retail

```text
World of Warcraft/_retail_/Interface/AddOns/LevelPercent/
```

### Classic

```text
World of Warcraft/_classic_/Interface/AddOns/LevelPercent/
```

## Paso 2: Activar el addon

1. Abre World of Warcraft.
2. En la pantalla de selección de personaje, abre **AddOns**.
3. Activa **LevelPercent**.
4. Entra con tu personaje.

## Paso 3: Mover, bloquear o redimensionar

Al entrar, verás un cuadro con una barra visual y el porcentaje de avance de nivel.

- Arrastra el cuadro con clic izquierdo para moverlo.
- Usa la esquina inferior derecha para cambiar el tamaño.
- Usa `/lp lock` para bloquearlo.
- Usa `/lp unlock` para volver a moverlo.

## Nota sobre la versión del cliente

Si aparece como desactualizado, marca **Load out of date AddOns** o cambia el valor `## Interface` dentro de `LevelPercent/LevelPercent.toc` según tu versión de WoW.
